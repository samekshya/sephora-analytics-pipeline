# Presentation

[`sephora_pipeline_deck.html`](sephora_pipeline_deck.html) is the deck. Open it in any
browser — no build step, no server, no dependencies beyond the `assets/` folder beside it.

| | |
|---|---|
| Advance / go back | `→` `←`, space, or swipe |
| Jump to a slide | `Home`, `End`, or the `#5` URL fragment |
| Fit to screen | Automatic — the 1920×1080 stage scales to the window rather than reflowing |

Present it full-screen (`F11`). The stage letterboxes, so the layout on the projector is the
layout you proofed.

## The trend figure

Slide 9's chart is generated by [`build_charts.py`](build_charts.py) from
`dw.vw_review_volume_by_month` — the same view the dashboard reads, so the two cannot state
different numbers. The two price charts on slide 10 are cropped dashboard captures; the trend
is rendered instead because a screenshot of a 176-month span comes out either too wide for a
slide or too small to read the 2020 dip.

```powershell
py .\presentation\build_charts.py     # -> assets/chart_trend.svg
```

Needs the warehouse up and `plotly` + `kaleido` installed (both are in `requirements.txt`).

## Diagrams

The three diagrams on slides 4, 5 and 6 are generated by
[`../docs/diagrams/build_diagrams.py`](../docs/diagrams/build_diagrams.py), not drawn. After
changing a schema, regenerate and copy the SVGs across:

```powershell
py .\docs\diagrams\build_diagrams.py
Copy-Item .\docs\diagrams\*.svg .\presentation\assets\ -Force
```

The deck embeds the SVGs, so they stay sharp at any projector resolution; `docs/diagrams/*.png`
are the raster copies the README and other Markdown render.
